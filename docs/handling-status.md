# Handling proof — 1 October 2026

`Assets/Alabama/Scenes/HandlingCourse.unity` is the first playable slice. It uses the dressed industrial street but keeps the static `IndustrialStreet.unity` visual review intact. `E46_Drive.prefab` has a Rigidbody and four WheelColliders, with a collision proxy on the chassis. `VehicleInput` samples Unity Input System actions each rendered frame; `ArcadeCarController` consumes the latest command on the fixed physics step. This keeps input devices separate from physical behavior. `E46Tuning.asset` owns mass, centre of mass, suspension, grip, torque, braking, steering, and downforce values. A following camera and small telemetry overlay make test drives useful without introducing a finished HUD.

The rear axle drives and both axles brake. A held brake engages reverse once forward speed falls below 1.2 m/s; the handbrake applies rear braking and temporarily reduces rear lateral grip. Steering angle declines from 33° toward 10° as speed approaches 50 m/s. Reset restores the scene spawn pose and clears velocity. Rigidbody interpolation and continuous dynamic collision detection are enabled; wheel simulation uses configured substeps. These are first-pass values, exposed for tuning rather than hard-coded into a hidden solver.

The saved-scene Play Mode integration tests verified acceleration, braking, reverse, steering, reset, sustained high-speed straight-line contact, curb contact, and barrier containment. On this machine, the acceleration case measured **61.3 km/h after 3 seconds**, and the straight-line test ended **97.1 m down the road at 174.1 km/h** after an initial 48 m/s launch. These are scenario observations, not a full performance or handling benchmark. Seven Edit Mode and four Play Mode tests passed. A strict Windows development build succeeded at `builds/handling-course/Alabama.exe`; a headless player startup reached scene loading without reported exceptions. The graphical player and feel still require an interactive drive review.

Current limits: the course is a straight visual corridor, so there is no connected route or steering through corners. The car has no engine sound, traffic, damage, polished gauges, reverse lights, or camera look-back. The later strengthened straight-line test launched at 200.2 km/h, checked lane and suspension bounds on every fixed step, and ended at 198.4 km/h; it does not prove high-speed corner or curb stability. Frame-rate comparisons, a 30-minute automated drive, and 1080p GPU profiling are recorded in [qualification status](qualification-status.md). Player feedback and art approval against the supplied screenshot remain open.
