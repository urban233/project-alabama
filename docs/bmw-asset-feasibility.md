## Selected route

Use BlenderCentral's existing BMW M3 E46 as the base, as explicitly requested by the user on 1 October 2026. This replaces the earlier original-geometry fallback. Adapt it to a grounded, lower polygon game asset, retaining realistic proportions and smooth body surfaces. Preserve the untouched download, attribution, license, editable adaptation, repeatable export tooling, independent wheel pivots, and validation records. The adaptation is not CC0; retain the applicable CC-BY-SA license. The included license confirms CC-BY-SA 3.0; a copy is preserved with the source records.

The base is an E46 M3 rather than an already verified GTR race variant. After inspecting it, adapt the wide body, wing, race wheels, and silver/blue material direction toward the supplied reference. A final GTR match is a separate visual review requirement. Use the road-car measurements as a proportion anchor; racing details are visual estimates rather than certified measurements.

The first review concerns the rear silhouette, wheelbase, roof/window profile, wide arches, wing, tail lights, front/side recognition, and silver/blue material direction. It remains a work in progress until the user accepts it against the supplied screenshot and the additional vehicle references. Do not describe an unreviewed procedural sedan as a finished BMW model.
